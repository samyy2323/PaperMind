# ByT5 OCR-correction training

Fine-tunes a ByT5 model that repairs TrOCR's handwriting-recognition errors, one page line at a time.

| File | Purpose |
|---|---|
| `papermind_byt5_all_in_one.py` | **One self-contained file**: data builder + trainer + evaluator. Generated by `bundle.py`. Use this in any notebook |
| `correction/*.py` | The same code as separate modules (what the tests use). Edit these, then run `python bundle.py` |
| `make_zip.py` | Zips `correction/` for the older multi-file notebook |

## Run (any notebook with a GPU; A100 recommended for `base`)
```python
# cell 1:  !pip -q install rapidfuzz        (do NOT pin transformers / tokenizers)
# cell 2:  upload papermind_byt5_all_in_one.py, then
exec(open('papermind_byt5_all_in_one.py').read())
main(['--preset', 'smoke', '--out', '/content/run1'])            # ~5 min sanity check first
main(['--preset', 'base',  '--out', '/content/run_base',
      '--iam-dir', '/path/to/iam',                                # real handwriting (official IAM or Kaggle maxicode/iam-handwriting)
      '--test-manifest', '/path/to/my_pages/test.tsv'])           # optional: your own real lines, used ONLY for testing
```
Or from a terminal: `python papermind_byt5_all_in_one.py --preset base --out run_base --iam-dir ...`

Presets: `smoke` (3k lines, byt5-small) / `small` / `base` (120k lines, byt5-base, 6 epochs, IAM x2) / `large` (byt5-large, batch 16 x 4 accumulation).
Any option you add overrides the preset (`--epochs 8`, `--n-lines 200000`, `--lr 1e-4`, `--patience 3` ...). Finished stages are skipped on re-run.

## What the report tells you (`final_report.json`)
* `cer_after` vs `cer_before` - must go down.
* `over_correction.rate` - lines that were already right but got changed (aim for ~0).
* `preservation.rate` - how often the model "fixed" a student's *wrong fact* (aim for ~0; a correction model must never change content).
* `source_iam` / `source_own_test` - the honest real-handwriting scores.

## Data options
`--iam-dir` IAM lines (+ `--iam-lines`, `--iam-repeat`) | `--manifest` your own line images, TSV `image<TAB>text` (trained on) |
`--test-manifest` same format, test only | `--files` syllabus/textbook/answer text or PDFs | `--wiki-n` Simple-Wikipedia sentences.

## Use the trained model in PaperMind
Copy the `ckpt/` folder to `backend/models/byt5-correction/`, set `CORRECTION_MODEL_PATH=./models/byt5-correction` in `backend/.env`,
restart the backend. `apply_guard` keeps the original OCR text whenever the model rewrites a line too aggressively.

## Notes
* GPUs without bf16 (T4/P100) train in fp32 (fp16 is unstable for ByT5): use `small`, or expect `base` to be slow.
* No internet: Wikipedia and font downloads are skipped with a warning; the built-in seed sentences, IAM and simulated noise still work.
